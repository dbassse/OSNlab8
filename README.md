
## 🐸 Обработка аудиосигналов с помощью нейронных сетей

1. **Классификация музыкальных жанров (GTZAN Dataset)**: Извлечение спектральных и временных признаков аудиофайлов для автоматического определения музыкального стиля.
2. **Распознавание эмоций по речи (Speech Emotion Recognition — SER)**: Кросс-датасетное тестирование моделей классификации эмоционального окраса речи с использованием наборов данных **TESS** и **SAVEE**.

## 📂 Структура проектов и ноутбуков

### 1. `l8z1.ipynb` & `l8z2.ipynb` — Музыкальный классификатор (Жанры)
Проекты посвящены классификации аудиозаписей из популярного набора данных **GTZAN** (10 классов: *blues, classical, country, disco, hiphop, jazz, metal, pop, reggae, rock*).

* **Пайплайн обработки данных**:
  * Загрузка оригинального набора аудиофайлов в формате `.au` и предобработанных векторов из файлов сериализации `.pickle`.
  * Извлечение ключевых признаков аудиосигнала с помощью библиотеки `librosa`:
    * Спектральная хромограмма (`chroma_stft`)
    * Мел-кепстральные коэффициенты (`MFCC`)
    * Среднеквадратическая амплитуда (`RMSE`)
    * Спектральный центроид (`spectral_centroid`), ширина полосы (`spectral_bandwidth`) и спад частоты (`spectral_rolloff`)
    * Скорость пересечения нуля (`zero_crossing_rate`)
  * Масштабирование признаков с помощью `StandardScaler` из библиотеки `sklearn`.
* **Архитектура нейросети**: Полносвязная многослойная нейронная сеть (Dense Multi-Layer Perceptron), включающая слои `BatchNormalization` для стабилизации обучения и `Dropout` для предотвращения переобучения (Regularization).
* **Метрики**: Оценка качества модели с помощью матрицы ошибок (`ConfusionMatrixDisplay`), визуализация распределения вероятностей предсказаний для конкретных треков.

### 2. `l8z3.ipynb` — Распознавание эмоций на речи (SER)
Фокус работы смещен на анализ человеческой речи и решение задачи бихевиорального анализа через голос.
